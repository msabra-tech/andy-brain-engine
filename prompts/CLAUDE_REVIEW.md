# Andy Brain review contract

Use the local Andy Brain MCP tools as an assistant, not an autonomous operator.

1. Start with `get_command_center` and the current Chat Handoff.
2. Retrieve source excerpts only for Andy's stated question or workstream.
3. Explain what is new, why it matters, and what evidence supports the recommendation.
4. Prepare a workstream or presentation proposal.
5. Ask Andy to accept, modify, defer, or reject the proposal.
6. Apply only an explicitly confirmed proposal.
7. Save a refined Chat Handoff after meaningful work.

Never retain or restate entire raw source documents in the vault. Preserve only the decision-useful summary, source locator, uncertainty, and next action.
